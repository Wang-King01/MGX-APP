# 周末出逃 · 周末城市探索指南（MGX-APP）

把城市，逛成你的地图。一个「周末灵感补给站」产品 Demo：选择城市 → 设定天气 / 预算 / 人数 → 获取真实推荐。

## 功能亮点

- **5 座城市**：杭州 / 北京 / 上海 / 厦门 / 广州，一键切换，每城独立主视觉
- **6 大场景**：自然户外 · 艺术文化 · 美食漫游 · 城市漫步 · 咖啡书店 · 夜游市集，每城每场景 10+ 场地，共 300+ 条真实场地
- **真实数据**：场地坐标与地址来自高德地图 POI，票价经携程 / 同程等公开资料核验；卡片配图由高德静态地图按真实坐标生成
- **真实推荐**：按用户选择的天气（晴 / 多云 / 雨）、人均预算、同行人数进行加权评分（天气 40 + 预算 25 + 人数 20 + 热度 15），并给出推荐理由
- **实时天气**：侧栏天气卡接入高德天气 API，展示所选城市实时温度 / 风向 / 更新时间（失败自动降级为模拟数据）
- **高德导航**：详情页一键跳转高德地图导航到场地
- 搭子广场 / 探索手记 / 我的收藏 / 分享攻略 等本地演示功能完整保留

## 技术栈

Vite + React 19 + TypeScript，无后端依赖（数据静态内置），localStorage 本地持久化。

## 快速开始

```bash
cd app/frontend
npm install
npm run dev      # 开发
npm run build    # 构建产物输出到 dist/
```

## 数据说明

- 场地清单、坐标：高德地图 Web 服务 API（POI 检索）
- 票价 / 人均：整理自携程、同程等公开资料，仅供参考，出发前请核实
- 采集与转换脚本见 `scripts/`（POI 采集 → Python 数据模块 → 生成 `src/explore-data.ts`）

## 目录结构

```
app/
  frontend/        # Vite + React 前端（核心）
    src/explore-data.ts   # 300+ 条场地数据（自动生成）
    src/heroes.ts         # 城市主视觉（内嵌 base64，保证自包含）
    src/pages/Index.tsx   # 主页面
  backend/         # MGX 生成的后端脚手架（本 Demo 未依赖）
scripts/           # 数据采集 / 转换脚本与原始 POI 数据
```
